# 时间表附属页（schedule.html）方案

## 定位
把《陈本祯规则部考研时间安排计划表》做成独立附属页：北京时间联动显示“当前理论上该干什么”，并与主站实际计时状态做简短对比。纯前端、零流量增量（30 秒本地刷新一次）。

## 新增文件（3 个）
1. **`schedule.html`** — 页面骨架（与 reminders/call 同模式）
2. **`static/js/schedule-data.js`** — 时间表数据（可编辑）：
   - 8 个时段：00:00-00:30 夜间收尾（0:30 上床）/ 00:30-07:30 睡眠（预计 7h）/ 07:30-08:00 起床到自习室（实习日 7:30 起；非实习日预案 9:30 作为备注行）/ 08:00-12:00 上午自习（4h，特殊 2.5h）/ 12:00-12:30 午餐 / 12:30-14:30 午休+下午准备（2h）/ 14:30-18:00 下午自习（3.5h）/ 18:00-18:30 晚餐 / 18:30-24:00 晚上自习（5.5h）
   - 每时段含 kind 标记（study/meal/rest/sleep/prep），用于理论对比
   - 规则速查数据：≥20min 有效 / >30min 去自习室 / 单次休息≤20min 严禁娱乐 / 迟到立即开始不等待不补偿 / 违规=次日禁大餐奶茶
3. **`static/js/schedule.js`** — 渲染 + 联动逻辑

## 页面功能
1. **全天时间表**：时段行（时间/事件/时长/备注），北京时间**当前时段行高亮** + “现在”标记 + 该时段已流逝进度条
2. **理论 vs 实际对比卡**（顶部常驻）：
   - 理论 = 当前时段（schedule-data 按北京时间匹配）
   - 实际 = `Store.getActiveTimer()`（running+study → ✅「正在学习，符合安排」/ paused → ⚠️「暂停中」/ null → ❌「未在计时」/ 非学习类 → 显示实际内容）
   - 休息/睡眠时段：计时中 → ℹ️「自觉加练」；未计时 → ✅「符合安排」
3. **规则速查面板**（收起式，黑金样式沿用提醒栏目）
4. 每 30 秒本地刷新当前时段/进度/对比（无网络请求）

## 入口
首页「链接大全」新增 chip：`schedule.html`（clock-3 图标，时间表）——仅此一个入口

## 明确不做
- 不改主站 `TIME_BLOCKS`（作息边界维持 8/12/17:30/23:40 现状；本页理论状态独立于主站三块配置。若将来想把三块/电池也切到新表，另行提出）
- 不做实习日/非实习日切换器（双预案仅作信息展示）
- 不接 Supabase（实际状态读本地 Store 即可，云端同步由主站负责）

## 工程事项
- `theme.css` 追加 sc-* 样式（沿用黑金/卡片风）
- `sw.js` SHELL 加 schedule.html + 2 个 JS；版本三重升级 **v1.5.0 / v93 / 7 页 meta（含新页）**
- 部署工作流已是 `cp *.html` 通配，新页自动发布（上次的坑已堵）
- 验证：node --check + 本地冒烟（当前时段高亮/对比卡状态/移动端宽度截图）

## 不改项
主站代码零改动（本页为纯只读的附属展示页）；print 场景由纸质表继续承担。
