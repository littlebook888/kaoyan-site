## C. 违规记录模块（完全独立 · 任务页最底部独立卡，签到卡之后）
- 新文件 `static/js/violation.js`（checkin 同款 IIFE，仅 tasks.html 挂载）
- 数据：events 表行 `{ id: "viol-<时间戳ms>", date, title: "violation", note }`，可多条/天；每条带小「删除」钮（deleteEventRow 显式推删）
- 登记：点「登记违规」→ 记录当前日期+时间，违规内容可选填（输入框）
- 惩罚算法（按日期排序逐条结算）：首条 = 当日+次日；后续违规日期 ≤ 当前期末 → 期末+1（一日多次/违规期内再犯一次 +1 日）；违规日晚于期末 → 新一轮（当日+次日）
- 震撼横幅（仅任务页）：违规中时在内容最顶（签到气泡上方）——红黑渐变、⛔ 大字「违规惩罚期间」+ 期间起止 + 「不得：娱乐 · 通话 · 聚餐」+ 脉冲发光；页面内布局推挤，不发系统通知
- 独立卡：details 折叠，summary = ⛔ 徽章 + 「违规记录」 + 状态胶囊（违规中·剩N天 / 正常）；零联动断言锁死

## D. 每日签到分项切日（新增，用户 2026.10.05 指定）
- **切日锚点**：ima、workbuddy/trae = 自然日 0 点；**不背单词 = 凌晨 4 点**（0:00~3:59 期间签到算前一天，签前一天的到）
- **数据重构**：单条合并记录 `ck-<日期>` → 每项独立 `ck-ima-<D>` / `ck-wb-<D>` / `ck-bb-<D>`（D = 各自锚点日：`dateOf(now − 锚点小时)`，ima/wb 减 0h、bb 减 4h）；旧 `ck-<D>` 兼容读取 = 三项在该自然日均已完成（best-effort，向后兼容）
- **行为**：「已完成今日签到任务」一键完成所有**当前锚点日未完成**的项（各记各的锚点日，如凌晨 1 点按下 = ima/wb 记今天、bb 记昨天）；每项 ✓ 圈按各自状态独立点亮；卡片状态胶囊显示「已完成 N/3」；全部完成才显示完成行
- **撤销**：只撤销最近一次按下所创建的行（LS 记录 last-press 行 id 集，deleteEventRow 显式推删）——避免误删昨天晚上的真实签到
- **气泡**：18 点后仍按「存在未完成项」出现，但列出**具体未完成的项**；0~4 点区间本来不触发（<18 点），无额外处理
- 卡片 hint 补充切日说明（不背单词按凌晨 4 点切日）
