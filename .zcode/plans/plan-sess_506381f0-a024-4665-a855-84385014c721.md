**static/js/tasks.js**

1. 计算行（`cetGap` 下方）加：
```js
// ★ v1.28.5 理想目标：10-20 收官（中性陈述：距理想目标还多 X 天）
const idealMs = new Date(2026, 9, 20).getTime();
const idealGap = Math.max(0, Math.round((etaMs - idealMs) / 86400000));
```

2. 文案行（六级文案后）加一段：
```
· 距理想目标（10-20）还多 ${idealGap} 天
```

按你选的口径：**中性陈述**——超期时不加警示色，就写「还多 30 天」这样的中性数字（`Math.max(0, …)` 保证提前完成时不出现负数）。

10-20 日期与现有六级 12-12 一样就地硬编码（挨着 cetMs，符合该函数现状；不引入 config 依赖）。
