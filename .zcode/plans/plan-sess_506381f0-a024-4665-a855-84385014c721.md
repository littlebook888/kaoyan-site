新增「超时计时器」：倒计时铃响后未开始下一段时，显示已超时多久（v1.24.0）

## 场景与设计决策

倒计时（学习/休息都算）到点响铃后，人不在场、没来得及开下一个计时，手机放那边——回来时能看到一个**小超时计时器**持续显示"已超时 X 分 X 秒"。

调研结论决定了三条设计原则：
1. **不碰 active_timer/Store**——铃响后 active_timer 已删除并广播 STOP（store.js 10 秒停止保护窗、远端停止墓碑都会和"往 Store 写超时状态"打架），所以做成**设备本地的纯显示状态**（模块变量 + localStorage 键 `kaoyan:overtime_since`，仿现有 `kaoyan:countdown_hms` 的持久化惯例）；
2. **借用现有 250ms tick 节拍器**驱动显示，不新增定时器；
3. 跨设备不同步（active_timer 行已删，做跨设备要改同步协议，代价大不值）——本设备显示，其他设备开始新计时时（订阅回调收到 at）本页自动消失。

## 实现（4 个文件）

**① static/js/timer.js（核心）**
- 模块顶部加 `let overtimeSince = 0; let overtimeInfo = null;` + LS 键 `kaoyan:overtime_since`（存 `{since, kind}`，刷新后恢复显示）；
- **置位**：`finishCountdown()` 内 `at = null; Store.setActiveTimer(null);` 之后、`render()` 之前：`overtimeSince = now; overtimeInfo = { kind: k };` 并写 LS（此时 now/k 都是现成变量）；
- **清位（三处）**：`startCountdown` 与 `startCountup` 开头（本机开始任何新计时）；`change:active_timer` 订阅回调里 `if (at)` 分支（其他设备/标签页开始计时 → 本页超时件消失）；
- **驱动**：`tick()` 顶部——`if (!at && overtimeSince)` 更新 `#overtimeVal` 文案（用现有 `fmt()` 传正数超时秒数）；`else if (at && overtimeSince)` 兜底清位；
- **渲染开关**：`render()` idle 分支挂 `#overtimePill` 显隐；
- **手动关闭**：`#overtimeClose` 点击 → 清状态 + 删 LS（铃响了但人回来了、暂不想开计时的情况）；
- focusMode 的结束流程（focusCountdownFinished）不动。

**② timer.html**：`.card.timer-stage` 内加悬浮 pill：
```html
<div id="overtimePill" class="overtime-pill" style="display:none">
  ⏰ <span id="overtimeKind">学习</span>已结束 · 已超时 <b id="overtimeVal">00:00</b>
  <span class="ot-tip">该开始下一段了</span>
  <button id="overtimeClose" aria-label="关闭">×</button>
</div>
```

**③ static/css/theme.css**：`.overtime-pill` 固定悬浮（bottom 居中、tabbar 上方 96px、z-index 50——低于标签抽屉遮罩的 60，避免盖住结束后的补标签抽屉），琥珀底色仿 `.break-hint` 配色 + 胶囊阴影仿 `.sync-badge`。

**④ static/js/clock.js（首页联动，一行级）**：时钟卡的"当前无计时"气泡——若存在未清的超时状态，改显「⏰ 已超时 X 分」琥珀色气泡（读同一个 LS 键；手机放那边后解锁直接看首页也能看到）。

## 显示口径
- 适用：一切倒计时（学习/休息/自由）铃响后；正计时、暂停不触发（暂停时倒计时冻结，本就不"超时"）；
- 文案：学习 → "学习已结束 · 已超时 X"；休息 → "休息已结束 · 已超时 X"；
- 不重复响铃（铃响时的 3 声 + 系统通知已足够，超时件纯视觉）；超时期间不写任何记录（落盘时长仍以设定时长为准，现状不变）；
- 清除途径：开始任何新计时（本机或本账号其他设备）/ 点 × 手动关 / 无自动过期（放了整夜回来还能看到超时了多久——这正是需求）。

## 不做的事
- 不改 active_timer 协议、不做跨设备超时同步；
- 不重复响铃/震动；
- 超时期间不写额外记录、不改统计口径；
- focusMode 结束流程不加超时件。
