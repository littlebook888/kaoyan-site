# 题库功能复刻 · 开源项目评估与路线建议

> 目的：为「考研个人网站管理系统」新增 **306 西综题库 + 多端同步** 功能，评估 GitHub 上可合法复刻的开源项目，明确版权边界，给出推荐技术路线。
> 受众：后续接手维护的 AI / 开发者。
> 评估日期：2026-08-26

---

## 0. 一句话结论（先看这条）

- **可以复用「代码架构」，不能复制「题库内容」。** 开源许可证（MIT/Apache）只授权代码，不授权题目本身。306 真题、天天师兄/学成《选择题》均受版权保护。
- 用户给的参考链接 `rray1228/neike-306-tiku` **不能合法复刻**（无 LICENSE + 仓库内含受版权题册 PDF + 私有部署需电脑常开）。
- **推荐路线 A（Supabase 真后端）**：fork `awsify` 或 `QuizStack`（均 MIT，Supabase 栈），合并进本项目**已规划的 Supabase 实例**，UI 改为 66ccff 洛天依风，题库内容自备。

## 1. 版权边界（必须严格遵守）

| 维度 | 可否复刻 | 说明 |
|---|---|---|
| 项目的**代码/架构**（MIT/Apache 明确授权） | ✅ 可以 | fork 后改造、重新署名即可 |
| 项目的**题库内容**（题目文本、答案、解析） | ❌ 不可以 | 内容版权独立于代码许可证 |
| 自己录入的笔记 / 教材转录 / 自有标注 | ✅ 可以 | 用户对内容拥有权利 |
| Apache-2.0 / 明确授权的**数据集**（如 ModelScope 医学题库） | ✅ 可，但需核验来源 | 确认数据集本身授权链干净再使用 |
| 抓取医考帮 / 阿虎等 App 的题目 | ❌ 不可以 | 违反对方 ToS + 内容版权 |
| 打包「天天师兄/学成」题册 PDF 或提取结果 | ❌ 不可以 | 受版权保护，且在他人仓库中即属转载 |

**实操红线**：题库页面只展示**用户自己维护的内容**。若提供「示例题」，须为用户自行撰写的示例，不得是真题原文或他人讲义。

## 3. 重点说明

### 3.1 用户给的链接为什么排除
- 直接请求 `/LICENSE` 返回 404 → 无许可证，默认保留所有权利，代码不可复制。
- `physiology/` 目录含 `source/天天学成选择题（生理学）.pdf` 与 `extracted-questions.json` → 仓库内即转载受版权资料。
- README 明确私有部署「电脑需要保持运行题库服务」→ 违背本项目「免费、不依赖本机常开」目标。
- 目前仅完成内科/生理，病理/外科仍是 OCR 空目录 → 覆盖不全。

### 3.2 推荐底本：awsify / QuizStack（MIT + Supabase）
- 已内置：Supabase Auth、Postgres 表、RLS 行级安全（按 `user_id` 隔离）、题库 CRUD、批量导入 JSON、进度跟踪。
- 与我们**已在规划的 Supabase 项目**天然兼容——计时器/任务/题库共用同一实例，避免两套后端。
- 前端交互（章节索引、错题训练、键盘 1-5/←→、选项重排）可借鉴 Med-Quiz；Markdown 出题可借用 BMB 的 `generate-questions.mjs`。

### 3.3 零后端替代：Elyxira（MIT + GitHub 同步）
- 用 GitHub 仓库当「云端数据库」，通过 Git Data API 批量读写题库/笔记/标签，跨设备导入导出。
- 优点：完全免费、零运维、无需 Supabase。
- 缺点：非实时多人、受仓库体积限制、需 GitHub 账号。

## 4. 推荐复刻路线（路线 A：Supabase 真后端）

1. **fork 底本**：`AbhiramVSA/awsify`（或 `mrsho240/QuizStack`），保留 MIT 声明与署名。
2. **合并 Supabase**：复用本项目已申请的 Supabase 项目（与计时器/任务同一实例）。建表：`questions`、`user_progress`、`wrong_questions`（参考 awsify 的 `mcq_questions` + QuizStack 的 `quizzes/questions` schema，加 RLS）。
3. **改 UI 皮肤**：套用本项目 `static/css/theme.css` 的苹果风卡片 + 66ccff 洛天依配色，替换原项目默认主题。
4. **前端交互借鉴**：章节/错题/键盘快捷键来自 Med-Quiz；Markdown→JSON 出题脚本来自 BMB。
5. **内容自备**：提供「从 Markdown/JSON 录入」入口；示例题仅用用户自写内容；如引入 ModelScope 数据集须先核验授权。
6. **多端验证**：沿用现有三端同步思路（localStorage 兜底 + BroadcastChannel 同浏览器 + Supabase Realtime 跨设备）。
